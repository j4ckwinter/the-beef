open an agent session here and say what you want to work on. [AGENTS.md](AGENTS.md) is the entry point. if your client doesn't load it automatically, ask it to read that file first.

## what's here

- [AGENTS.md](AGENTS.md): where to start and where the projects live.
- [steering](steering/working-preferences.md): how i like to work.
- [wiki](wiki/pancake-stack.md): project context, source links, and things worth knowing before changing anything.

[Pancake Stack](https://github.com/j4ckwinter/pancake-stack) supplies the workflows. this repo doesn't duplicate them. personal skills can come later if there's something the shared plugin doesn't cover.

## where it lives

keep this checkout beside the projects it describes:

```text
dev/
├── the-beef/
├── pancake-stack/
└── pancake-stack-evals/
```

paths in the project map are relative to this repo. links inside wiki pages are relative to the page itself. the sibling links work locally; use the source links for browsing on GitHub.

## keep it useful

read the page for the project you're working on, then check the repo itself. the wiki can go stale. project instructions and code are the place to verify what is true now.

keep lasting facts and useful gotchas here, with links to where they came from. task history and raw logs belong elsewhere.
